# 💰 برنامه مدیریت مالی — نسخه موبایل

نسخه‌ی موبایل برنامه مدیریت مالی با Flet

## ✨ ویژگی‌ها

- 📊 مدیریت کارت‌های بانکی
- 💵 ثبت درآمد و هزینه
- 🔁 انتقال بین کارت‌ها
- 📈 نمودارهای مالی (میله‌ای، دایره‌ای)
- 📩 پارسر هوشمند پیامک‌های بانکی
- 🔗 یادگیری خودکار اتصال شماره حساب به کارت
- 💾 دیتابیس SQLite
- 🎨 رابط کاربری مدرن با گرادیانت

## 🏦 بانک‌های پشتیبانی‌شده

- ✅ بانک سپه
- ✅ بانک پاسارگاد
- ✅ بانک اقتصاد نوین
- ✅ بانک صادرات
- ✅ بانک ملی

## 🛠️ تکنولوژی‌ها

- Python 3.13
- Flet 0.24.1
- SQLite

## 📁 ساختار پروژه


├── main.py # نقطه ورود
├── core/ # منطق کسب‌وکار
│ ├── database.py # لایه دیتابیس
│ ├── models.py # کلاس‌ها
│ ├── services.py # سرویس‌ها
│ ├── reports.py # گزارش‌ها
│ └── validators.py # اعتبارسنجی
├── sms/ # سرویس پیامک
│ ├── sms_parser.py # پارسر پیامک‌های بانکی
│ └── sms_service.py # مدیریت پیامک‌ها
└── ui/ # رابط کاربری (در حال توسعه)
