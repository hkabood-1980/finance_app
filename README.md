# 💰 برنامه مدیریت مالی

برنامه‌ی مدیریت مالی شخصی با پایتون — نسخه دسکتاپ

## ✨ ویژگی‌ها

- 📊 ثبت و مدیریت کارت‌های بانکی
- 💵 ثبت درآمد و هزینه
- 🔁 انتقال بین کارت‌ها
- 🐷 پس‌انداز
- 📈 نمودارهای مالی (میله‌ای، دایره‌ای، دونات)
- 📋 گزارش‌های متنوع
- 🔍 جستجوی پیشرفته
- 💾 پشتیبان‌گیری و بازگردانی (فرمت zip)
- 🌙 حالت تاریک/روشن

## 🛠️ تکنولوژی‌ها

- Python 3.13
- CustomTkinter (رابط گرافیکی مدرن)
- SQLite (دیتابیس محلی)
- Matplotlib (نمودارها)

## 📦 نصب و اجرا

### پیش‌نیازها

```bash
pip install customtkinter matplotlib
